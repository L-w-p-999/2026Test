# JS-第二题：找出含一份可疑证据的片段

成步堂律师正在调查一起案件。检察官按时间顺序提交了一系列证据，记录在数组 `nums` 中：

- `0` 表示普通证据。
- `1` 表示可疑证据。

为了逐个调查疑点，成步堂决定：只有恰好包含一份可疑证据的连续片段，才会列入本轮调查。

请你帮助成步堂统计，一共有多少个符合条件的连续证据片段，并在 `solution.js` 中实现函数 `countSuspiciousSegments(nums)`，返回片段数量。

**注意：**

- 片段必须连续且非空。
- 每个片段必须恰好包含一个 `1`，没有 `1` 或包含多个 `1` 都不符合条件。
- 起止位置不同，算不同的片段，即使片段内容相同。
- 输入数组只包含 `0` 和 `1`，长度不超过 `100`；空数组返回 `0`。

## 示例 1

**输入：** `nums = [0, 1, 0, 1]`

**输出：** `6`

**解释：** 以下 6 个片段恰好包含一份可疑证据，下标从 `0` 开始：

- 下标 `0～1`：`[0, 1]`。
- 下标 `0～2`：`[0, 1, 0]`。
- 下标 `1～1`：`[1]`。
- 下标 `1～2`：`[1, 0]`。
- 下标 `2～3`：`[0, 1]`。
- 下标 `3～3`：`[1]`。

## 示例 2

**输入：** `nums = [0, 0]`

**输出：** `0`

**解释：** 所有片段都没有可疑证据，因此没有符合条件的片段。

## 示例 3

**输入：** `nums = [1, 1]`

**输出：** `2`

**解释：** 两份可疑证据各自组成一个符合条件的片段；包含两份证据的片段 `[1, 1]` 不符合条件。

## 示例 4

**输入：** `nums = []`

**输出：** `0`

**解释：** 没有证据，无法组成非空片段。
