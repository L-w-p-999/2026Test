# JS-第一题：模拟退格输入

给定一个只包含小写英文字母和 `#` 的字符串 `text`，请你模拟输入过程，并返回最终显示的字符串。

输入规则如下：

- 从左到右依次处理字符串中的字符。
- 小写英文字母表示输入该字母。
- `#` 表示删除前一个尚未删除的字母。
- 没有字母可删时，忽略当前的 `#`。

请在 `solution.js` 中实现函数 `processInput(text)`。

## 示例 1

**输入：** `text = "abc#d"`

**输出：** `"abd"`

**解释：** 输入 `a`、`b`、`c` 后，遇到 `#` 删除 `c`，再输入 `d`，最终得到 `"abd"`。

## 示例 2

**输入：** `text = "ab##c"`

**输出：** `"c"`

**解释：** 输入 `a`、`b` 后，连续两个 `#` 依次删除 `b` 和 `a`，再输入 `c`，最终得到 `"c"`。

## 示例 3

**输入：** `text = "##a#"`

**输出：** `""`

**解释：** 开头两个 `#` 没有字母可删，因此忽略。输入 `a` 后，最后一个 `#` 将其删除，最终得到空字符串。

## 示例 4

**输入：** `text = ""`

**输出：** `""`

**解释：** 没有输入任何字符，最终得到空字符串。
